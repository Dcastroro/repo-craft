# Review rubric

A shippable skill must satisfy all:

- Trigger describes both capability and usage context.
- Body contains decisions and workflow, not generic education.
- Default path reads only necessary context.
- Repository claims cite discoverable local sources.
- Scripts are deterministic, bounded, and tested.
- Writes have explicit scope and preserve manual content.
- Maintenance signal is clear.
- No secrets, personal data, or production mutations are embedded.

Flag duplicated source text when a link or focused reference would preserve context.
