# Opportunity rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Repetition | Rare | Occasional | Frequent |
| Repository specificity | Generic | Partly local | Cannot infer safely |
| Error cost | Cosmetic | Rework | Security, data, release |
| Evidence stability | Volatile | Mixed | Durable |
| Tooling gap | Enforced | Partly enforced | Judgment remains |

Recommend creation at 7 or above. A security-critical invariant may override the
threshold when the skill points to authoritative evidence rather than copying it.
