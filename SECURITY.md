# Security policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities or leaked credentials.
Use [GitHub private vulnerability reporting](https://github.com/Dcastroro/repo-craft/security/advisories/new)
and include:

- the affected file or skill;
- reproduction steps;
- the expected security boundary;
- the observed impact;
- any suggested remediation.

Do not include real credentials, personal data, or third-party private content
in a report. Reports will be acknowledged through the private advisory.
